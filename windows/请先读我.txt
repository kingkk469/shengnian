声年 Windows 免费版 0.3.2

1. 把整个 ZIP 解压到一个普通文件夹，例如 D:\声年。不要直接在压缩包里运行，也不要只拿走 exe；_internal 文件夹是必需的。
2. 双击“声年.exe”。本包内置 Python、离线转写模型和音频解码工具，无需安装 Python 或下载模型。
3. 点击主界面的“API 配置”，粘贴你自己的 DeepSeek API Key，然后保存。Key 保存在本机，重启后自动读取；本地录音、转写不需要 API Key。
4. 点击开始录音，或导入已有录音；首次加载转写模型可能要等待一会儿。

API 获取：打开 https://platform.deepseek.com ，在自己的账户中申请 API Key。AI 调用费用由你的服务商账户承担。SnapAny Key 是可选项，仅用于相应视频链接解析。

数据保存在 %LOCALAPPDATA%\VoiceJournal\Data。
API Key 在该目录的 runtime\api-keys.json；此文件包含明文密钥，不要把自己的数据目录发给别人。
如果电脑已设置 DEEPSEEK_API_KEY 环境变量，重启时该环境变量优先于界面保存的 Key；需要换 Key 时请同时更新或移除旧环境变量。

麦克风：在 Windows 设置 → 隐私和安全性 → 麦克风 中允许桌面应用使用麦克风；在声年界面选择实际输入设备。
录音和转写在本地运行。调用 AI 总结、卡片等功能时，相关文字直接发送到你配置的 API 服务商。

支持 Windows 10/11 64 位。建议至少 8 GB 内存、10 GB 可用磁盘。无声年账号、邀请码、激活或收费套餐。
当前 EXE 未做代码签名，Windows 可能显示未知发布者提示；请核对发送者和随包校验值后再运行。
