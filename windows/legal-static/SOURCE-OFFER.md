# 对应源码

声年业务代码以 MIT 协议免费开源。本包对应的应用源码放在 `legal/sources/shengnian-0.3.2-source.zip`；项目仓库为 https://github.com/kingkk469/shengnian 。本地 Windows 改动尚未同步到远端仓库，以随包源码为准。

本版本未修改 Qt、PySide6、Shiboken6 或 FFmpeg 上游源码。以下对应源码已随包放在 `legal/sources`：

- `VoiceJournal-LGPL-Sources-6.11.1.zip`：Qt、PySide6 和 Shiboken6 的对应源码。
- `VoiceJournal-FFmpeg-LGPL-Sources-20260728.zip`：所用 FFmpeg shared 构建及其依赖的对应源码。

转发软件时请保留整个目录及这些源码包。校验信息见 `SOURCE-BUNDLE.json` 和 `FFMPEG-MANIFEST.json`。
