# 声年 Mac 版

独立应用面向苹果芯片 Mac（M1 或更新芯片），要求 macOS 14 或更新版本。Intel Mac 暂不支持。

独立应用已在 GitHub 的苹果芯片 Mac 环境构建成功，并通过实际转写、声纹和原生界面检查。[下载完整安装包](https://github.com/kingkk469/shengnian/actions/runs/33759616541/artifacts/9896177635)（约 2.45 GB，需登录 GitHub，2026-09-17 前下载保存）。详细结果见 [构建状态](BUILD_STATUS.md)。

## 安装独立应用

下载的 ZIP 内有 `shengnian-macos-arm64.dmg` 及校验文件。DMG 包含 Python、运行库、FFmpeg、中文语音识别、语音活动检测、标点和声纹模型，无需另行安装 Python、Homebrew 或模型。

1. 解压下载的 ZIP，打开 DMG，把“声年”拖入“Applications（应用程序）”。
2. 从“应用程序”打开声年。
3. 点击“API 配置”，填写自己的 DeepSeek API Key。录音和本地转写可以不填。
4. 点击开始录音，按 macOS 提示允许声年访问麦克风。

本版没有 Apple 开发者公证。如系统阻止首次打开，请在“系统设置 → 隐私与安全性”中按系统提示确认打开。不要关闭系统的全局安全保护。

默认使用 CPU 转写；不承诺 MPS 加速。运行时请预留足够的内存和录音存储空间。

## 数据和配置

用户数据保存在 `~/Library/Application Support/VoiceJournal/Data`，更新应用不会覆盖这里的录音、转写、笔记或配置。

- 配置文件：数据目录中的 `config.toml`，第一次启动自动创建。
- API 配置：数据目录中的 `runtime/api-keys.json`，文件权限仅允许当前用户读写。请不要分享该文件。
- 模型：随应用内置，普通录音转写不需要联网下载模型。
- AI 总结：需要联网，相关文字直接发给你配置的服务商，并使用你自己的 API 额度。
- 文件入口：在应用内点击“文件”，可以打开本地数据目录；Obsidian 为可选功能。

## 构建与验证

在苹果芯片 Mac 的 Python 3.12 环境中执行 `bash macos/build.sh`，会依次安装固定依赖、运行测试、编译解码器、下载公开模型、封装应用、运行冻结应用自检并制作 DMG。

自动检查覆盖进程锁、VAD、内置解码器、中文 ASR 和声纹实际推理、Cocoa 主窗口和历史窗口，以及 DMG 完整性、挂载内容和应用签名。模型测试使用模型仓库的公开示例音频。

Mac 云主机无法代替物理麦克风、USB 设备热插拔、合盖睡眠和长时间录音的硬件验收。实际结果和剩余限制记录在 [验证记录](VALIDATION.md)。

开发者需要从源码运行时，请看 [源码安装说明](SOURCE_INSTALL.md)。
